## EventBus

Typed async-first event bus returned by `new Event({ … })`. See [Server](/packages/events/server) for emit/dispatch and SSE wiring, [Listeners](/packages/events/listeners) for `on` / `once` / `subscribe`, and [Namespaces](/packages/events/namespaces) for `namespace` and channel scoping.

## ChannelEmitter

Channel-scoped emitter from `event.channel(...names)` — same emit API with `channels` merged into metadata. See [Channel](/packages/events/channel) for client subscribe and [Server](/packages/events/server) for emit.
